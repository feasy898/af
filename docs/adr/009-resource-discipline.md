# ADR-009: 资源并行纪律（与 AB 测试会话共存）

- 状态：已裁决（2026-10-24，编排者；当日磁盘 99% 事故后固化）

## 背景

2026-10-24：根分区一度 99%（8.5G 余量），phase2-dsl 工作树创建失败；同机另一会话在跑 AB 测试（容器负载重）。当日回收 ~46G（afbuild-align2 9.9G、target/debug/incremental 6.4G、8 个空闲 fix4 工作树 ~39G，分支全部保留）。

## 裁决（对所有第二阶段任务包生效，模板已嵌入）

1. **开工先看盘**：任何重构建/大批量操作前 `df -h / /tmp`；`/` 余量 <15G 或 /tmp 使用 >80% 即停止并上报编排者。
2. **构建目录**：一律 `CARGO_TARGET_DIR=~/afbuild-<任务名>`；**严禁占用 af/target**（在役钉字节二进制区，按 状态观测/护栏rollout手册.md 保护；其 incremental 已清且不再重建）。
3. **工作树**：仅在派发实现任务时创建，任务合并后立即 `git worktree remove`（分支保留）；不预留。
4. **容器**：第二阶段容器命名一律 `phase2-` 前缀，与 AB 线（afbench-*/mcode-*）隔离判活；用毕即删。
5. **大文件**：遵守 设计/分流默认根约定.md 默认根；/tmp 只放白名单三类件。
6. **对其他会话零干扰**：不动 AB 线容器/进程/文件；工厂守护进程（keepalive/sched/watch）在 ADR-008 切流前零接触。
