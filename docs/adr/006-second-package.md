# ADR-006: 第二配置包 = 研究报告包

- 状态：已裁决（2026-10-24，编排者；对齐用户澄清）

## 背景

用户澄清（2026-10-24）：DSL 是"描述单体 harness 与多 agent 协作"的任务中立语言，**不按代码/视频/研究分业务域**；一切任务具体性（工具、提示词策略、工件类型、验证器）挂在配置包/组件上，不进入语言。

## 裁决

1. 两个验证用配置包：**软件工程包**（git/终端/测试工具集、ACI 风格接口、代码工件类型与验证器）与**研究报告包**（web 检索工具、报告工件类型、rubric/引用双验证器）。
2. 配置包 = `packages/<name>` 下的声明集合（工具集/技能库/工件类型/验证器四类资源 + manifest），经组件注册接口绑定（ADR-002），**语言核心零改动即支持**——这正是任务中立性的证明方式。
3. 研究报告包选择理由：第三阶段（大规模论文阅读→策略投影到 DSL）的刚需，第二阶段产出直接被复用；判分可离线（rubric/引用核对），不依赖外部评分服务。
4. 机器检查判据（G4 验收）：删除全部 `packages/` 后，DSL 语法规范与编译器完整自洽，非领域 golden 用例照常通过。
